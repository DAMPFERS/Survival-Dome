# Тесты симулятора купола

Комплексный набор тестов для проверки всех компонентов симулятора.

## 📦 Установка зависимостей

```bash
pip install -r requirements-test.txt
```

## 🚀 Запуск тестов

### Все тесты
```bash
python tests/test_runner.py
```

### По категориям
```bash
# Только тесты параметров (StateStore)
python tests/test_runner.py --category state

# Только тесты узлов
python tests/test_runner.py --category nodes

# Только правила зависимостей
python tests/test_runner.py --category deps

# Только кризисы
python tests/test_runner.py --category crises

# Интеграционные тесты
python tests/test_runner.py --category integration

# Управление временем
python tests/test_runner.py --category time

# Потокобезопасность
python tests/test_runner.py --category threads
```

### Дополнительные опции
```bash
# С измерением покрытия кода
python tests/test_runner.py --coverage

# Параллельный запуск (быстрее)
python tests/test_runner.py --parallel

# Подробный вывод
python tests/test_runner.py --verbose

# Комбинация опций
python tests/test_runner.py --category nodes --verbose
```

### Прямой запуск через pytest
```bash
# Из корневой директории
cd Janus/server/simulation
pytest tests/

# Конкретный файл
pytest tests/test_state_store.py

# Конкретный тест
pytest tests/test_nodes.py::test_solar_inverter_generates_power

# С покрытием
pytest tests/ --cov=dome_simulator --cov-report=term-missing
```

## 📝 Категории тестов

### 1. StateStore (test_state_store.py)
- Чтение/запись одного параметра
- Чтение всех параметров узла
- Чтение всех узлов системы
- Обновление нескольких параметров
- Персистентность между тиками
- Обработка ошибок
- Snapshot системы
- Потокобезопасность чтения

### 2. Узлы (test_nodes.py)
**Энергетика:**
- Генерация солнечных панелей
- Суточный цикл освещённости
- Влияние health на выработку
- Саморазряд батарей
- События при критическом заряде
- Расход топлива дизелем
- Отключение линий при перегрузке

**Климат:**
- Дрейф температуры
- Температурные шоки
- Накопление CO2
- Работа скрубберов
- Засорение фильтров

**Жизнеобеспечение:**
- Расход воды
- Переработка воды
- Генерация кислорода
- Накопление отходов

**Производство:**
- Выполнение заданий
- Завершение работ
- Прерывание при потере питания
- Отмена заданий

**Инфраструктура:**
- Агрегация статуса системы
- Аварийное освещение
- Износ конструкций
- Сетевые узлы

### 3. Зависимости (test_dependencies.py)
- Энергобаланс: избыток заряжает батареи
- Энергобаланс: дефицит разряжает батареи
- Отключение нагрузок при дефиците
- Приоритет отключения (производство → климат → жизнеобеспечение)
- Автозапуск дизеля при <20% батареи
- Автоостанов дизеля при >60% батареи
- Связь CO2 скруббера и сенсора
- Влияние вентиляции на климат
- Влияние вентиляции на CO2
- Переработка воды → бак
- Критические события → износ
- Дефицит энергии → аварийное освещение

### 4. Кризисы (test_crises.py)
**PowerLossCrisis:**
- Запуск кризиса
- Отключение целевого узла
- Публикация события
- Длительность кризиса
- Восстановление после завершения
- Ручная остановка

**CO2SpikeCrisis:**
- Увеличение генерации CO2
- Влияние на все сенсоры
- Восстановление множителя

**TemperatureAnomalyCrisis:**
- Применение температурного шока
- Влияние на зоны
- Кастомная величина шока

**SolarDegradationCrisis:**
- Снижение health панелей
- Снижение выработки
- Необратимость деградации

**Общие:**
- Несколько кризисов одновременно
- Защита от повторного запуска
- Список активных кризисов
- Кастомные параметры

### 5. Интеграция (test_integration.py)
- Полный суточный цикл
- Серия производственных заданий
- Энергетический кризис → восстановление
- CO2 кризис → реакция скруббера
- Каскадные отказы
- Вмешательство оператора
- Сохранение/загрузка состояния

### 6. Управление временем (test_time_control.py)
- Пауза останавливает изменения
- Возобновление продолжает работу
- Ускорение времени (x2, x4)
- Изменение time_scale во время работы
- dt=0 при паузе
- Накопление симуляционного времени

### 7. Потокобезопасность (test_thread_safety.py)
- Параллельное чтение из нескольких потоков
- Параллельная запись через API
- Управление во время тика
- Snapshot во время работы

## 🛠️ Утилиты (helpers.py)

- `wait_for_condition()` - ожидание выполнения условия
- `assert_event_published()` - проверка публикации события
- `simulate_for_seconds()` - прогон симуляции на N секунд
- `simulate_for_ticks()` - прогон на N тиков
- `get_event_count()` - подсчёт событий
- `wait_for_crisis_end()` - ожидание завершения кризиса
- `assert_parameter_in_range()` - проверка диапазона параметра
- `collect_parameter_over_time()` - сбор значений во времени

## 🎯 Фикстуры (conftest.py)

- `simulator` - базовый симулятор (tick_interval=1.0)
- `fast_simulator` - ускоренный симулятор (time_scale=4.0)
- `running_simulator` - уже запущенный симулятор
- `event_collector` - коллектор событий
- `crisis_params` - параметры для тестирования кризисов

## ⚙️ Конфигурация

Тесты используют короткие интервалы для быстрого выполнения:
- `tick_interval=1.0s` (вместо стандартных 4.0s)
- `time_scale=1.0` или `4.0` (для ускорения)
- Короткие кризисы (4-8 секунд вместо 60-90)

## 📚 Добавление новых тестов

1. Выберите подходящий файл или создайте новый
2. Используйте фикстуры из `conftest.py`
3. Именуйте тесты описательно: `test_<что_проверяем>()`
4. Добавляйте краткие комментарии
5. Запустите тест локально перед коммитом

```python
def test_my_new_feature(running_simulator):
    """Краткое описание, что проверяется."""
    sim = running_simulator
    
    # Действие
    sim.control("node_1", "action")
    
    # Проверка
    assert sim.get("node_1", "param") == expected_value
```

- pytest-timeout >= 2.1.0

## 📞 Поддержка

При проблемах с тестами:
1. Проверьте, что все зависимости установлены
2. Запустите тесты с `--verbose` для детального вывода
3. Проверьте логи симулятора
4. Убедитесь, что симулятор корректно останавливается между тестами
