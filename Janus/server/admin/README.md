# Админ-панель купола

Веб-панель администратора: вся телеметрия (агентский вид и истина), кризисы, режимы узлов и
любые управляющие воздействия с полным доступом админа.

```
python admin_panel.py                                   # сервер ws://localhost:8765, ключ из data/Hash-keys/admin.txt
python admin_panel.py --server ws://192.168.1.10:8765   # другой сервер купола
python admin_panel.py --key <ключ> --port 8080          # ключ явно (или DOME_ADMIN_KEY)
```

Откройте `http://127.0.0.1:8080`. Зависимость — только `websockets` (как у сервера).

## Как устроено

`admin_panel.py` подключается к `server_integrated.py` с админским ключом и держит соединение
(переподключается сам). Он же отдаёт статическую страницу (`static/`) и WebSocket `/ws` для браузера:
телеметрию пересылает всем открытым страницам, запросы страниц — серверу, ответы — обратно.
Ключ в браузер не попадает. По умолчанию страница слушает только `127.0.0.1` — через неё
выполняются любые админские команды; `--host 0.0.0.0` открывает её в сети.

## Вкладки

- **Обзор** — время купола, пауза/скорость, активная команда, запуск 90-минутной смены и её отчёт,
  энергосистема, линии щитка (вкл/выкл, взвод и эмуляция защиты), интерлоки автоматики
  (блок/разблок/снять, доверие к данным), журнал автоматики с квитированием, активные кризисы.
- **Узлы** — все узлы: телеметрия агента, рядом истина (подменённые значения подсвечены),
  заморозки, режим real/virtual, любое действие узла (👷 — физические действия Оператора).
- **Кризисы** — каталог №1–49 и К1–К13 с запуском (параметры JSON), остановка, отчёты
  (исход, время реакции агента, штрафы), подмены и заморозки слоя телеметрии.
- **Окружение** — истинная погода, воздух зон, внешние угрозы, подмены кризисов, реальный инвертор.
- **Доступ** — права участника (`access_policy.json`): просмотр, правка по узлу, перечитать файл.
- **Журнал** — все запросы панели и ответы сервера.

## Ключи

Ключи лежат в `Janus/data/Hash-keys` (`admin.txt`, `team_1..4.txt`); их SHA-256 — в
`authorization/keys_config.json`. Перегенерация (старые ключи перестают действовать):

```
cd server/authorization
python generate_keys.py --out ../../data/Hash-keys
```

Файлы ключей исключены из git (`data/Hash-keys/.gitignore`).
