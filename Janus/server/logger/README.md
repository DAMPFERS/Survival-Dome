# Журнал участника

`participant_log.py` пишет то, что видит команда, в JSONL-файлы по дням. Один формат пишут
сервер (`server_integrated.py`, реальные смены) и генератор недельного лога
(`generate_week_logs.py`, виртуальный купол).

Формат для участников описан в [docs/participants/01_API.md](../../docs/participants/01_API.md),
раздел 11 — при изменении формата обновляйте его там.

Сервер: каталог `DOME_PARTICIPANT_LOG` (по умолчанию `logs/participant`, `off` — не писать),
период снимков телеметрии `DOME_PARTICIPANT_LOG_SNAPSHOT_S` (60 с). В журнал попадают
телеметрия после фильтра политики доступа, команды ключа команды с ответами, физические
действия Оператора из админки и сообщения песочницы. Действия организаторов (кризисы, время,
политика) и истинное состояние не пишутся.

Тест: `python -m pytest logger/test_participant_log.py`.
