Janus проект реализующий хакатон "Лига автономных систем"

# Архитектура

## Купол
Есть купол, в котором реализована инфраструктура, состоящая из реальных и виртуальных устройств, которыми можно управлять (или получать с них информацию) в рамках одной ллокальной сети. Сервер, точка входа в инфраструктуру купола, который заниматеся агрегацией переферии и прогонкой симуляции. Сервер предоставляет интерфейс взаимодействия с внешним миром.
Помимо этого, на сервере реализована программное решение для получения видеопотока с 3х ip-камер. Это для организаторов (видеонаблюдение) и запускается параллельно работе самого купоа.

## Площадка участников

Команды участников находятся в большом отдалении от купола. Задача команд заключается в реализации ИИ-агента, который может управлять инфраструктуройй купола (по API через сервер). Сам хакатон проходит  в 2 дня. 1й день образовательный, участники учатся получать доступ к куполу и поднимают агентов. На машине админа поднимаются 4 виртуальные копии купола для команд участников (в локальной сети). Участники получают свои уникальные ключи и прогоняют агентов на своих версиях куполов. Помимо этого в локальной сети поднимается: ИИ-чат помошник (quest-ai), предоставляющий помощь в работе, а также пример взаимодействия с реальным куполом; локальный сервер с базой знаний (Логи прошлых игр, бортовой журнал, информацию по куполу, участники плюсом получают клиента) data-server, для реализации RAG для агента (участники сами решают , что им нужно, а что нет).

На второй день команды поочередно отправляют одного представителя для выполнения производственной задачи (время выполнения полтора часа), за ходом выполнения которой должен следить ии-агент команды (сделать так, чтобы он без проблем смог ее выполнить). ИИ-агент команды получает ip адрес реального купола и запускается с hackathon-runner (проходит верификацию, что участники не нарушили регламент и правила)
