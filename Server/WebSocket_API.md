# WebSocket API сервера телеметрии

## Общая информация

-   **Протокол:** WebSocket
-   **Формат сообщений:** JSON UTF-8
-   **Порт по умолчанию:** `8765`
-   **URL:** `ws://<SERVER_IP>:8765`

После подключения сервер сразу отправляет текущее состояние системы,
затем примерно каждые **4 секунды** отправляет обновленную телеметрию.

------------------------------------------------------------------------

# Формат сообщений

Каждое сообщение содержит поле:

``` json
{
  "type": "<тип сообщения>"
}
```

Типы сообщений:

  type               Направление       Назначение
  ------------------ ----------------- --------------------------------
  telemetry          Сервер → Клиент   Текущее состояние оборудования
  control            Клиент → Сервер   Команда управления
  control_response   Сервер → Клиент   Ответ на команду

------------------------------------------------------------------------

# Телеметрия

Пример:

``` json
{
  "type": "telemetry",
  "data": {
    "climate": {
      "temperature": 23.7,
      "humidity": 48.2,
      "co2": 630
    },
    "power": {
      "solarGeneration": 1520.4,
      "battery": 83,
      "inverter_online": true,
      "channels": [
        {
          "id": 1,
          "name": "LIGHTING",
          "enabled": true,
          "power": 120.5
        }
      ]
    }
  }
}
```

## Поле climate

  Поле          Тип     Описание
  ------------- ------- -----------------------
  temperature   float   Температура, °C
  humidity      float   Влажность, %
  co2           int     Концентрация CO₂, ppm

## Поле power

  Поле              Тип     Описание
  ----------------- ------- -----------------------------
  solarGeneration   float   Генерация солнечных панелей
  battery           float   Заряд аккумулятора, %
  inverter_online   bool    Есть ли связь с инвертором
  channels          array   Список каналов нагрузки

## Канал нагрузки

  Поле      Тип      Описание
  --------- -------- ------------------
  id        int      ID канала
  name      string   Имя канала
  enabled   bool     Состояние
  power     float    Текущая мощность

### Каналы

  ID   Имя
  ---- -------------
  1    LIGHTING
  2    WATER PUMP
  3    GREENHOUSE
  4    WORKSHOP
  5    VENTILATION
  6    COMPUTERS
  7    REACTOR
  8    RESERVE

------------------------------------------------------------------------

# Управление

Поддерживается одна команда.

## Переключение канала

Запрос:

``` json
{
    "type":"control",
    "action":"toggle",
    "channel_id":3
}
```

Сервер инвертирует текущее состояние канала.

## Успешный ответ

``` json
{
    "type":"control_response",
    "success":true,
    "channel_id":3,
    "enabled":true,
    "power":84.5
}
```

## Ошибка

``` json
{
    "type":"control_response",
    "success":false,
    "channel_id":3,
    "error":"Device offline or command failed"
}
```

------------------------------------------------------------------------

# Типы данных

  Тип      Значение
  -------- --------------------------
  float    Число с плавающей точкой
  int      Целое число
  bool     true/false
  string   Строка UTF‑8

------------------------------------------------------------------------

# Алгоритм работы клиента

1.  Подключиться к `ws://SERVER_IP:8765`.
2.  Получить первое сообщение `telemetry`.
3.  Обрабатывать входящие сообщения `telemetry`.
4.  При необходимости отправить сообщение `control`.
5.  Дождаться `control_response`.
6.  Продолжать получать телеметрию.

------------------------------------------------------------------------

# Особенности

-   Сервер поддерживает несколько клиентов одновременно.
-   Телеметрия отправляется периодически без запроса.
-   После подключения не требуется авторизация.
-   Если соединение разорвано, клиент должен выполнить повторное
    подключение.
-   Неизвестные `channel_id` игнорируются сервером.
