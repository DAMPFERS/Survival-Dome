# Купол — интерфейс мультиагентного чата

## Файлы

- `index.html` — структура страницы;
- `styles.css` — оформление и адаптивность;
- `app.js` — сценарий, таймер и синхронное обновление;
- `README.md` — эта инструкция.

## Запуск

Все файлы должны находиться в одной папке.

Откройте `index.html` в браузере.

Для разработки удобно использовать расширение Live Server в Visual Studio Code.

## Где редактировать сценарий

Откройте `app.js` и найдите массив `EVENTS`.

Каждое событие может:
- добавить сообщение в чат;
- обновить параметры справа.

## Цветовые уровни карточек

- `ok` — зелёный;
- `warn` — жёлтый;
- `danger` — красный;
- `muted` — серый.

## Типы сообщений

- `system`;
- `agent`;
- `telemetry`;
- `warning`;
- `danger`;
- `decision`;
- `result`.
